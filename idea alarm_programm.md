# Idea: Alarm Program (Windows PC Alerts)

## 1) Коротко о продукте

**Alarm Program** - это легковесное приложение для Windows, которое автоматически отправляет уведомления в Telegram/Discord о состоянии ПК.

Продукт решает простую, но регулярную боль: пользователь хочет быстро узнавать, что происходит с его компьютером, **без сложных панелей мониторинга** и без настройки серверной инфраструктуры.

---

## 2) Какая проблема решается

Сценарии, где это нужно:

- домашний ПК/сервер включился без владельца;
- компьютер перезагрузился после сбоя или обновления;
- нужно понять, когда ребенок/сотрудник реально запускал ПК;
- удаленный рабочий компьютер "упал" и снова поднялся;
- у пользователя несколько ПК и он хочет минимальный контроль без RMM-систем.

Сейчас люди обычно:

- проверяют вручную через AnyDesk/TeamViewer;
- настраивают слишком сложные enterprise-инструменты;
- получают мало информации и слишком поздно.

---

## 3) Целевая аудитория

1. **Домашние продвинутые пользователи** (homelab, mini server, NAS рядом с Windows-машиной).
2. **Малые команды/офисы** без штатного администратора.
3. **Родители** (контроль времени включения детского ПК).
4. **Фрилансеры/разработчики** с удаленным рабочим ПК.

---

## 4) Ценность продукта (Value Proposition)

- **Локально и просто:** устанавливается как обычное приложение, стартует вместе с Windows.
- **Мгновенные алерты:** событие -> сообщение в Telegram/Discord.
- **Прозрачность:** хранит локальный журнал событий (что и когда произошло).
- **Без сложной инфраструктуры:** для MVP не нужен собственный сервер.

---

## 5) Основной функционал MVP

### Обязательные функции

1. Автозапуск при старте Windows.
2. Отправка уведомления "ПК включился".
3. Определение предыдущего события выключения/перезагрузки через Windows Event Log.
4. Тестовая отправка уведомления из интерфейса.
5. Локальный лог приложения.
6. Базовые настройки:
   - Telegram Bot Token;
   - Chat ID;
   - Discord Webhook URL (опционально);
   - типы уведомлений.

### Дополнительные функции (после MVP)

- heartbeat ("ПК в сети каждые N минут");
- уведомления при входе пользователя в систему;
- уведомления о смене IP;
- экспорт логов в файл;
- режим "тихие часы" (не отправлять ночью, кроме критики).

---

## 6) Почему продукт можно продать

Эта категория относится к "utility software": маленькая задача, понятная польза, низкий порог внедрения.

Сильные стороны для продаж:

- не нужно учить пользователя сложной системе;
- ценность видна в первый день;
- можно продавать как разовую покупку (low-friction);
- легко сделать free/pro модель.

---

## 7) Бизнес-модель

### Вариант A (самый простой старт)

- **One-time license**: $9-$19 за ПК.
- Плюс бесплатная trial-версия на 7 дней.

### Вариант B (гибрид)

- Free: 1 ПК, только Telegram, базовые события.
- Pro: $3-$5/мес:
  - несколько ПК;
  - Discord + Telegram;
  - расширенные типы алертов;
  - история и экспорт.

---

## 8) Что нужно по инфраструктуре

### Для MVP

- Сервер: **не обязателен**.
- Нужны только:
  - Telegram Bot API (через токен бота);
  - опционально Discord webhook.

### Когда понадобится сервер

Сервер имеет смысл добавить, если появятся:

- личный кабинет;
- синхронизация между устройствами;
- лицензирование и онлайн-активация;
- централизованные правила оповещений;
- cloud backup логов.

---

## 10) Риски и ограничения

- ложные/дублирующиеся события в Event Log;
- антивирус может настороженно относиться к автозапуску;
- нельзя обещать "100% мониторинг как в enterprise";
- важно корректно хранить токены (шифрование/DPAPI).

---

## 11) Критерии успеха MVP

- пользователь устанавливает и отправляет первый тест-алерт за <= 5 минут;
- >90% событий старта ПК сопровождаются корректным уведомлением;
- минимум 10 ранних пользователей, из них 3+ готовы платить;
- минимум 1 подтвержденный сценарий "сэкономил время/нервы".

---

## 12) Elevator pitch

"Alarm Program - это легкое Windows-приложение, которое за минуту настраивается и отправляет в Telegram/Discord уведомления о включении, перезагрузке и важных событиях ПК. Без сервера, без сложных дашбордов, просто рабочие алерты."
