# Backlog Alarm Program (C#)

Этот backlog рассчитан на MVP и разбит на задачи, которые можно брать в работу по одной.

Формат:
- **ID** — уникальный номер задачи
- **Приоритет** — P0 (критично), P1 (важно), P2 (желательно)
- **Оценка** — примерная сложность в часах
- **Зависит от** — какие задачи должны быть готовы до начала
