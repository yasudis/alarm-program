# Plan Alarm Program (C#) - общий план разработки

Этот документ фиксирует **обобщенный план** создания приложения. В будущем мы можем детализировать каждый этап в отдельные задачи и спринты.

---

## 1) Цель этапа MVP

Собрать рабочий релиз Windows-приложения на C#, которое:

- стартует вместе с системой;
- определяет ключевые события ПК (startup/shutdown/restart);
- отправляет уведомления в Telegram;
- имеет минимальный UI для настройки;
- ведет локальный лог.

---

## 2) Этапы разработки

## Этап 0. Подготовка

- Определить целевую платформу (.NET 8/9, Windows 10+).
- Выбрать UI-стек (WPF).
- Создать репозиторий и базовую структуру решения.
- Подготовить исходные требования MVP и критерии готовности.

Результат: каркас проекта и зафиксированный scope.

---

## Этап 1. Базовый каркас приложения

- Настроить слои (UI, Application, Domain, Infrastructure).
- Внедрить DI (Microsoft.Extensions.DependencyInjection).
- Подключить конфигурацию (appsettings + локальные пользовательские настройки).
- Настроить логирование (файл + EventLog по возможности).

Результат: "пустой", но правильно собранный проект.

---

## Этап 2. Подсистема событий Windows

- Реализовать сервис чтения событий из Event Log.
- Выделить типы событий:
  - запуск;
  - корректное завершение;
  - перезагрузка;
  - некорректное завершение (если возможно детектировать).
- Добавить защиту от дублей и ложных срабатываний.

Результат: стабильный поток доменных событий внутри приложения.

---

## Этап 3. Подсистема уведомлений

- Реализовать Telegram-канал отправки.
- Добавить форматирование сообщений (шаблоны).
- Реализовать тестовую отправку из UI.
- Добавить повторы/ограничения (retry/backoff) при временной ошибке сети.

Результат: надежная отправка алертов при событиях ПК.

---

## Этап 4. UI настроек

- Экран/окно настроек:
  - Bot Token;
  - Chat ID;
  - включение/выключение типов алертов;
  - кнопка "Проверить отправку".
- Валидация полей.
- Сохранение настроек локально (безопасно, с шифрованием чувствительных данных).

Результат: пользователь сам настраивает приложение без ручного редактирования файлов.

---

## Этап 5. Интеграция автозапуска и фонового режима

- Настроить запуск при старте Windows.
- Реализовать режим работы "в фоне" (tray/минимизация в системную область по желанию).
- Гарантировать корректное завершение приложения.

Результат: приложение работает автономно без постоянного открытия UI.

---

## Этап 6. Тестирование и стабилизация

- Unit-тесты ключевой логики:
  - фильтрация событий;
  - форматирование сообщений;
  - обработка ошибок.
- Интеграционные проверки:
  - тест на реальной машине Windows;
  - проверка после reboot;
  - проверка поведения без интернета.
- Ручной smoke checklist перед релизом.

Результат: стабильный MVP с понятным качеством.

---

## Этап 7. Сборка и доставка пользователю

- Настроить publish-профиль (single-file по необходимости).
- Подготовить installer (MSIX/другой удобный способ).
- Описать инструкцию первого запуска (Quick Start).
- Сформировать страницу продукта и скриншоты.

Результат: готовый установочный пакет и базовые материалы для продаж.

---

## 3) Общий roadmap после MVP

1. Добавить Discord webhook (если не был в MVP).
2. Реализовать heartbeat и уведомления о пропаже/восстановлении сети.
3. Добавить multi-device (при серверной части).
4. Ввести лицензию/подписку.
5. Добавить web-кабинет и историю событий.

---

## 4) Управление рисками

- Риск: нестабильная интерпретация Event Log.
  - Действие: таблица правил + fallback-логика + тесты на разных сценариях.
- Риск: блокировка антивирусом.
  - Действие: чистая подпись сборки, прозрачная документация, минимум подозрительных действий.
- Риск: утечка токенов.
  - Действие: шифрование и запрет вывода секретов в лог.

---

## 5) Definition of Done для MVP

MVP считается готовым, когда:

- приложение устанавливается и запускается на чистой Windows-машине;
- пользователь настраивает Telegram и получает тестовое сообщение;
- события запуска/перезагрузки реально отправляются;
- логи доступны для диагностики;
- есть краткая инструкция "установка -> запуск -> проверка".
